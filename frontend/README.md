# Tube Mill — Frontend (React + Vite)

## Setup

```bash
cd frontend
npm install
```

## Run

```bash
npm run dev
```

- **UI:** http://localhost:5173  
- API requests are proxied to the backend (see `vite.config.js`). Start the API from `../backend` first.

## Run frontend + backend together

From this folder:

```bash
npm run dev:all
```

## Build

```bash
npm run build
npm run preview
```
